================================================================
BHARAT GAMES - cPanel DEPLOYMENT GUIDE (v2 - AUTO DOMAIN)
================================================================

Ab deploy sirf 3 step ka hai:
  1. Code upload + SQL import
  2. config.php mein DB credentials (SIRF 1 FILE)
  3. 2 cron jobs

Domain khud detect ho jata hai - kahi bhi domain change karne
ki zarurat NAHI hai (http/https/Cloudflare sab auto handle).

----------------------------------------------------------------
STEP 1: UPLOAD + DATABASE
----------------------------------------------------------------
1. cPanel -> File Manager -> public_html
2. Code zip upload karke extract karo (zip root = site files:
   index.html, config.php, conn.php, admin/, pay/, apifolder/...)
3. cPanel -> MySQL Databases:
   - Database banao (cPanel prefix laga sakta hai)
   - User banao + password set karo
   - User ko database par ALL PRIVILEGES do
4. cPanel -> phpMyAdmin -> database select -> Import ->
   bhar42501_SQL_full_dump.sql -> Go
   (dump mein CREATE DATABASE/USE nahi hai - jo DB select karoge
    wahi import hoga)

----------------------------------------------------------------
STEP 2: config.php  (SIRF YE EK FILE EDIT KARO)
----------------------------------------------------------------
public_html/config.php kholo, sirf ye 4 lines change karo:

    define('DB_SERVER',   'localhost');         // cPanel: 'localhost'
    define('DB_USERNAME', 'cpaneluser_dbname'); // tumhara DB user
    define('DB_PASSWORD', 'tumharapassword');   // tumhara DB password
    define('DB_NAME',     'cpaneluser_dbname'); // tumhara DB name

Bas. Poore site ke 25+ connection files (conn.php, admin/*,
apifolder/*, serive/*, jdb/*, pay/*, cron_master.php) isi file
se credentials uthate hain. Kuch aur edit karne ki zarurat nahi.

DOMAIN: Automatic detect hota hai (HTTP_HOST + https/proxy
detection). SITE_DOMAIN constant CLI/cron links ke liye optional
hai - khali chhod do to bhi chalega.

----------------------------------------------------------------
STEP 3: PHP VERSION
----------------------------------------------------------------
cPanel -> MultiPHP Manager -> PHP 8.1 ya newer
Extensions (default on): mysqli, curl, mbstring, openssl, json

----------------------------------------------------------------
STEP 4: CRON JOBS (2 LINES - RESULTS KE LIYE ZARURI)
----------------------------------------------------------------
cPanel -> Cron Jobs -> Common Settings: Once Per Minute ->

Line 1 (master - saare games + payout sync + daily resets):
* * * * * php /home/YOUR_CPANEL_USER/public_html/cron_master.php >/dev/null 2>&1

Line 2 (fast tick - WinGo result 2-4s mein declare):
* * * * * php /home/YOUR_CPANEL_USER/public_html/wingo_fast_tick.php >/dev/null 2>&1

(YOUR_CPANEL_USER = cPanel username; Cron Jobs page par path
dikh jata hai. Dono lines "Once Per Minute" pe set karo.)

Web cron (cron-job.org / external) ke liye:
curl -s "https://YOUR-DOMAIN.com/cron_master.php?key=2c8938261d4aa749ce3190c36e6a71e1" >/dev/null 2>&1
curl -s "https://YOUR-DOMAIN.com/wingo_fast_tick.php?key=2c8938261d4aa749ce3190c36e6a71e1" >/dev/null 2>&1

cron_master.php handles: WinGo 30s/1m/3m/5m/10m, 5D, K3, TRX
WinGo (1m/3m/5m/10m) + WatchPay/QwackPay payout sync + midnight
resets. wingo_fast_tick.php WinGo ka open-period create +
settlement fast rakhta hai (result latency 2-4s).

----------------------------------------------------------------
STEP 5: VERIFY (2 MINUTE)
----------------------------------------------------------------
1. Site:  https://YOUR-DOMAIN.com/   (login page aana chahiye)
2. Admin: https://YOUR-DOMAIN.com/admin/
3. WinGo kholo - countdown chale aur har round ka result
   history mein aane lage (30s/1m/3m/5m)
4. cron_master.php?key=... browser mein kholo - JSON logs dikhega
